# 🏦 Projeto: Caixa Eletrônico (CLI ATM) em Python

Este é um projeto prático de um **Caixa Eletrônico** interativo que roda diretamente no terminal, desenvolvido durante a minha jornada de aprendizado em lógica de programação com Python.

O objetivo principal deste projeto foi aplicar conceitos fundamentais de desenvolvimento de software de forma estruturada, limpa e eficiente.

## 🚀 Funcionalidades

- **Definição de Saldo Inicial:** O sistema inicia com um saldo definido pelo usuário.
- **Consulta de Saldo:** Exibição clara do saldo atual formatado em Reais (`R$`).
- **Saques Inteligentes:** Validação para impedir saques maiores do que o saldo disponível em conta.
- **Depósitos Dinâmicos:** Atualização em tempo real do saldo ao realizar depósitos.
- **Menu de Navegação Contínuo:** Um fluxo interativo (via loops) que permite ao usuário realizar múltiplas operações até que ele decida sair.

## 🧠 Aprendizados Aplicados

Neste projeto, pude consolidar e colocar em prática os seguintes conceitos:

1. **Modularização com Funções (`def`):** Criação de escopos isolados e reutilizáveis para as lógicas de saque e depósito, passando e retornando parâmetros (`saldo`).
2. **Estruturas de Repetição (`while True`):** Controle do fluxo contínuo do sistema e tratamento de parada amigável utilizando `break`.
3. **Condicionais e Lógica de Negócio (`if/elif/else`):** Validação de regras essenciais, como impedir que a conta fique negativa.
4. **Tipagem e Conversão de Dados:** Manipulação de entradas do tipo `string` convertendo-as de forma adequada para `float` e `int`.
5. **Interação com Usuário:** Formatação de saídas numéricas para o padrão monetário brasileiro.

## 🛠️ Como executar o projeto

1. Certifique-se de ter o Python instalado na sua máquina.
2. Clone este repositório ou baixe o arquivo de código.
3. Abra o terminal na pasta do arquivo e execute:
```bash
python seu_arquivo.py
```
4. Siga as instruções no terminal para interagir com o sistema.
